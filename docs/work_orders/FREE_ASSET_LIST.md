# Free & under-$5 asset list (checked 2026-10-25)

**Where to put downloads:**
- Guns: `C:\Users\Devin\PROJECTS\bolt-and-sprocket-ultimate\assets\user_supplied\weapons\<name>\`
- Zombies, characters and animations: `...\assets\user_supplied\characters\<name>\` or `...\animations\<name>\`

Keep each download in its own folder.

**Licenses:**
- Every Sketchfab model below is **CC Attribution (CC-BY)**: free for commercial games, but **the artist must be credited**. Claude Code will add each credit to `docs/ASSETS.md` and the game's credits screen. Save the page link in a `SOURCE.txt` next to each download.
- Unity Asset Store items use the **Standard Unity Asset Store EULA**.
- Before you download anything, glance at the page's tags/description for **"NoAI"**. If it's there, skip that one.

**Style warning:** these come from different artists, so quality and look vary. Claude Code's shared weapon shader (Update 05) evens them out. For the most consistent look, use **TastyTony's "Low-Poly" series** for every gun it covers; it's one artist, 144 guns, clean and game-ready. Use the higher-detail models where TastyTony has no version.

Made for third-person, and the magazine is part of the body, so Claude would have to split it for reloads. Okay as filler.
