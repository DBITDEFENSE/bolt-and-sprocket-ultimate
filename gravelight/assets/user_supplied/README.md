# User-supplied assets

Put any asset you provide here. Every file needs a sibling `<filename>.LICENSE.txt` that says:
- where it came from (URL or "made by me"),
- the license (CC0, CC-BY 4.0, purchased license, etc.) and that it allows commercial game use,
- the attribution line, if one is required.

Every file here must also be listed in `docs/ASSETS.md`.
